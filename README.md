# 三国志战略版拆解案

本仓库用于沉淀《三国志·战略版》战斗数值模型与底层规则深度拆解案（第二版），以及相关游戏机制、系统与数值策划研究资料。

## 核心拆解案与数据库（第二版）

- **[第二版拆解案/](第二版拆解案/README.md)**：
  - **[第一部分：规则基底](第二版拆解案/第一部分/第一部分_规则基底.md)**（[网页阅读版](第二版拆解案/第一部分/第一部分_规则基底.html)）：时钟加载、三层状态机、伤兵蓄水池机制与沙盘宏观闭环。
  - **[第二部分：单体结算与战法投放](第二版拆解案/第二部分/第二部分_单体结算与战法投放.md)**（[网页阅读版](第二版拆解案/第二部分/第二部分_单体结算与战法投放.html)）：一击伤害拓扑、兵力非线性弹性与凹函数阻尼、方差心理学与 GaaS 生态。
  - **[战法数据库/](第二版拆解案/战法数据库/README.md)**：全量满级战法 JSON、武将图鉴及官方 40 个战斗状态规则库。
