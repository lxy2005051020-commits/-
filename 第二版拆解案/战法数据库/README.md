# 《三国志·战略版》战法、武将与状态官方数据库

本目录汇集了拆解案全篇（第一部分至第五部分）所依赖的全部战法、武将与状态机权威数据。所有战法名称、数值倍率、触发概率、适用兵种及官方状态定义均以此处为准。

## 二、官方 40 个具体状态分类速查

1. **持续性状态（8个）**：
   - 伤害类：灼烧 (`burn`)、水攻 (`flood`)、中毒 (`poison`)、溃逃 (`rout`)、沙暴 (`sandstorm`)、叛逃 (`rebellion`)
   - 恢复类：急救 (`first_aid`)、休整 (`recuperation`)
2. **功能性状态（17个）**：
   - 行动与连击：先攻 (`first_strike`)、遇袭 (`ambush`)、连击 (`combo`)
   - 伤害免疫与规避：规避 (`evasion`)、抵御 (`barrier`)、必中 (`sure_hit`)、警戒 (`vigilance`)
   - 目标与承伤：援护 (`guard`)、分担 (`damage_share`)、分摊 (`damage_split`)、铁索连环 (`chain_link`)
   - 反应与增益：反击 (`counterattack`)、群攻 (`cleave`)、洞察 (`insight`)、破阵 (`defense_pierce`)、倒戈 (`weapon_lifesteal`)、攻心 (`strategy_lifesteal`)
3. **控制状态（11个）**：
   - 动作限制：震慑 (`stun`)、计穷 (`silence`)、缴械 (`disarm`)、混乱 (`confusion`)
   - 效果限制：虚弱 (`weakness`)、禁疗 (`healing_ban`)、伪报 (`false_report`)
   - 目标与装备：嘲讽 (`taunt`)、挑拨 (`provoke`)、破坏 (`equipment_disable`)、捕获 (`capture`)
4. **其他（4个）**：
   - 会心 (`critical`)、奇谋 (`strategy_critical`)、看破 (`damage_reduction_pierce`)、威慑 (`intimidation`)
