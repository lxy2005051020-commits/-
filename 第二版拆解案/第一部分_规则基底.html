三国志·战略版战斗数值拆解 · 第一部分 · 2026-10-18

第一部分：规则基底——战斗如何运行，规则如何改变选择

本章核心主旨：战斗数值从来不是孤立的面板运算，而是通过“行动时序判定”、“状态路由分流”与“伤兵容量约束”三层底层状态机逐步兑现。相同的伤害或治疗数值预算，因目标解析、出手时效及触发机制的差异，会在战场上放大为数倍的胜负与战损差距。

注：本章基于实战战报解析与底层状态机推演，系统还原《三国志·战略版》战斗仲裁底座。战法数据与状态定义严格对齐本地满级战法数据库与官方状态目录（详见同目录《证据索引与口径说明.md》）。

1.1 战斗定位与战损闭环：胜负之后，还剩多少继续作战的能力

三人队伍的战前配置，决定了队伍的攻防分工：谁承担核心输出、谁吸收伤害、谁提供状态净化与伤兵恢复。进入战斗后，这些战前配置通过行动时序、目标选择与触发规则逐步兑现。在 SLG 战斗中，主将的生存具有绝对决定性意义：主将兵力归零即刻触发终战屏障判定，直接结算队伍溃败。因此，保护己方关键主将与优先压低敌方主将兵力，具备远高于平均杀伤副将的战术权重。

更为关键的是，SLG 的战斗从来不是单场孤立的竞技场决斗，而是整个宏观沙盘战争机器的战损转化器。单场战斗的价值，必须置于大地图资源与作战循环中进行闭环评估：

战前配置→战斗结算→战后状态→恢复与补充→再次出征

1. 战损与宏观资源消耗的刚性映射

  • 兵力即资源：战斗内损失的不可恢复兵力，直接线性映射为大地图上的资源消耗（粮食、铁矿、木材）与兵营征兵队列的时间成本（预备兵耗尽后的生产瓶颈）。
  • 重伤惩罚与时间真空：主将或副将兵力归零将触发武将“重伤状态”，强制进入 10 分钟行动冻结窗口（无法移动、调动、接战）。在瞬息万变的同盟集结与防线拉扯中，核心武将重伤意味着主力队伍瞬间瘫痪。
  • 战后伤兵转化：战斗结束后，战场内留存的伤兵在部队回城或在驻守营帐中按比例转化为存活兵力，而战斗内未被救治的“硬损耗”则永久消失，需重新征兵补齐。

2. 战斗胜负的多维评估模型

一次战斗至少需要从三个维度综合考量：是否完成战术目标、付出了多少硬性战损、还能否继续执行下一次任务。

战斗情境 只看单场胜负容易忽略什么 策划视角的宏观价值权衡
惨胜：获胜但核心主将剩余兵力极低 获胜标签掩盖了部队已丧失连续作战能力的事实 主将面临重伤风险，回城补兵与征兵耗时极长，前线推进被迫中断，连穿能力断崖式下跌
战平：未取胜但成功达成拖延与消耗目标 战平不等于无功而返，单次平局往往蕴含巨大战略价值 在九宫八卦城防下成功顶住敌方高红突击队，强行拖延其攻城节奏，消耗敌方主力体力，为盟友争取集结窗口
过度续航：携带过多恢复战法降低单场战损 治疗战法同样挤占极其宝贵的战法槽位 牺牲了爆发输出与硬控制能力，战斗被动拖长至多回合，导致承受更多敌方控制与跳伤，错失压制击杀敌方主将的黄金窗口

战前配置的核心权衡，正是为了在“击杀效率”与“战损耐受度/续航能力”之间寻找帕累托最优解。这也是后续所有机制与收益分析的系统起点。

1.2 结算时序：先确定何时轮到，再判断此刻能做什么

准备阶段：官方时序机制——“单武将内部四类串行，全场按武将速度轮流出场”

官方确立的核心战法执行优先级顺序为： $$\text{被动战法} \longrightarrow \text{阵法} \longrightarrow \text{兵种战法} \longrightarrow \text{指挥战法}$$

但必须明确其底层运行维度：官方规则是以“单武将”为基本单元进行串行调度的，绝非全场所有武将按战法大类进行“全局统一分块”！

1. 准备阶段状态机的双层调度架构

准备阶段的底层执行管线可解构为精密的双层嵌套循环： 1. 外层循环（武将速度定序）：准备阶段首先获取全场 6 名武将的实时面板有效速度，由高到低建立准备阶段出场队列（例如：武将 A（极速） $\to$ 武将 B $\to$ 武将 C $\to \dots$）。 2. 内层循环（单武将内部四类串行）： - 轮到武将 A 出场时，系统严格按【被动 $\to$ 阵法 $\to$ 兵种 $\to$ 指挥】的时序依次结算武将 A 自身携带的战法； - 武将 A 的上述战法完全执行完毕后，控制权才交接给下一个顺位的武将 B； - 轮到武将 B 时，武将 B 同样在其自身内部完整执行【被动 $\to$ 阵法 $\to$ 兵种 $\to$ 指挥】。

2. 实战数据中“跨武将伪逆序”现象的根因破解

在对 5,000 份实战确定性排序战报（4,976 份包含有效准备阶段）进行大数据复核时，如果脱离武将主体、只按全场日志出现的时间戳粗暴统计战法类型，就会看到大量所谓的“逆序”现象：

检验维度 比较阶段关系 有效配对样本数 正序样本数 逆序样本数 实战本质与机制归因
全场跨武将 被动 -> 阵法 1,636 1,266 370 并非规则失效：高速武将的阵法先于低速武将的被动执行
全场跨武将 阵法 -> 兵种 1,314 1,314 0 稳定正序：阵法在当前样本中稳定先于兵种结算
全场跨武将 兵种 -> 指挥 2,132 838 1,294 并非规则失效：高速武将的指挥先于低速武将的兵种执行
单武将内部 被动 -> 阵法 -> 兵种 -> 指挥 全量 严格按序 0 官方铁律：单武将自身内部严格遵循四类先后顺序

真相大白：例如高速辅助曹操（武将 A）携带了指挥战法【暂避其锋】，而低速法师司马懿（武将 B）携带了被动战法【士别三日】。在战报日志中，武将 A 已经完整走完了其自身的全部流程（包括最后的指挥战法【暂避其锋】），随后才轮到武将 B 出场开始走其自身的被动战法【士别三日】。只看日志标签的分析者会误以为“指挥怎么跑到被动前面去了”，而实际上这恰恰是“武将按速度轮流出场、每个武将内部严格执行四类优先级”的必然结果！

3. 策划维度的配将策略推论

这一底层机制在战前配将中具有极高的实战指导价值： - 速度决定准备阶段的“免伤与状态压制窗口”： 核心指挥减伤战法【暂避其锋】（降低智力最高受到的兵刃伤害、武力最高受到的谋略伤害各 40%）、【抚辑军民】必须由高速辅助携带，抢先于敌方准备阶段的伤害型战法建立免伤壁垒； - 单武将内部的属性链式读取： 单武将内部严格的“被动 $\to$ 阵法 $\to$ 兵种 $\to$ 指挥”时序，确保了武将自身的被动战法（如夏侯惇【刚烈不屈】提供的统率加成、被动战法【百炼成钢】的全属性提升）能优先结算完毕，并立即作为基底数值，被自身后续结算的阵法（如【锋矢阵】）或指挥战法（如【抚辑军民】）完整读取，形成自洽的数值加成闭环。

正式回合：行动层级划分与动作许可检查

进入正式回合后，系统每回合首先仲裁行动顺序。依据官方状态目录与项目确认规则，行动顺序遵循严格的三层优先层级模型： 1. 纯先攻层（优先级 $+1$）：持有【先攻】状态的武将优先行动（如兵种战法【白马义从】前2回合先攻、阵法【八门金锁阵】使主将前3回合先攻）。 2. 普通速度层（优先级 $0$）：无特殊时序状态的常规武将，按实时有效速度严格排序。若武将同时持有【先攻】（$+1$）与【遇袭】（$-1$），两者相互抵消归零，武将直接落入普通速度层。 3. 纯遇袭层（优先级 $-1$）：持有【遇袭】状态的武将（如受到指挥战法【铁骑驱驰】前2回合全体遇袭压制）落入末尾层级。 同层武将依据其实时面板有效速度降序排列；当回合内顺序一旦确立，中途获得或失去先攻均不进行动态插队重排。

“轮到行动”绝不等于“所有动作都能执行”。 武将每回合先进入自身的行动开始窗口，持续性状态（如休整、灼烧、中毒等）在该窗口依次结算；随后系统检查控制状态，判定行动许可： - 【震慑】（控制状态）：无法行动，彻底封锁自然行动，跳过当回合所有主动动作； - 【计穷】（控制状态，如受【落凤】、【弯弓饮羽】）：仅封锁主动战法发动许可，普通攻击正常执行； - 【缴械】（控制状态，如受【盛气凌敌】前2回合缴械）：仅封锁普通攻击许可，主动战法正常判定。

普通攻击全流程与三大实战决策节点

一次完整的普通攻击，其状态机流转包含严密的判定链条：

普攻许可检查 → 初始选敌 → 援护/目标重定向处理 → 最终目标的防御与伤害结算 → 合格受击反应（急救判定） → 反击批次结算 → 若仍满足存活与终战条件，再进入突击战法与连击机会。

在此流转中，有三个彻底决定战局走向的实战关键节点：

  1. 配速与净化时点（【草船借箭】、【刮骨疗毒】）：
  2. 辅助武将配速必须精准“卡速”在主力核心输出之前（保持 1~3 点微弱速度领先）。
  3. 机制根因：辅助武将在行动节点发动【草船借箭】（主动，65%概率清除我军群体负面并施加急救）或【刮骨疗毒】（主动，40%概率清除兵力最低单体负面并治疗），解除核心输出身上的【震慑】、【计穷】或持续灼烧/中毒，核心输出随后行动即可恢复行动许可，打出爆发输出；若辅助速度落后于输出，主力行动时已被判定跳过，滞后净化无法追回当回合已经丢失的出手权。
  4. 援护的目标重定向与受击承伤（【镇扼防拒】、【千里驰援】、援助特技）：
  5. 援护（功能性状态）是在普通攻击伤害结算前，强制将攻击目标改写为援护者，而非“原目标受击后再转移伤害”。
  6. 机制根因：武将满宠自带战法【镇扼防拒】（指挥）为副将施加援护并赋予休整，将针对脆弱主将的平A全数引流至高统率副将，不仅规避了主将被爆头风险，更能主动触发援护者的受击被动机制（如武将夏侯惇自带战法【刚烈不屈】受击造成兵刃反击、武将程普自带战法【勇烈持重】受到伤害35%概率解控并震慑敌方、被动战法【魅惑】受到普攻45%概率使攻击者陷入混乱/计穷/虚弱），实现由守转攻。
  7. 反击与终战阻断的风险博弈（【气凌三军】、【后发制人】）：
  8. 标准反击（功能性状态，如【气凌三军】、【后发制人】）在受击伤害结算完成后、突击战法与后续连击之前插入执行。
  9. 机制根因：若攻击者在打出首记普攻后兵力残血，反击批次若直接击杀攻击者，系统将立即触发死亡屏障，其后续配置的突击战法（如【当锋摧决】）与第二段连击将被强制阻断，伤害直接蒸发。因此高频连击面对反击肉盾阵容时存在严重的负面反噬风险。

1.3 伤害与状态：用效果入口解释克制关系

伤害的双轴系统与“叛逃”的设计定位

底层战斗中，任何一次伤害事件均由两条独立维度定义： - 伤害路线：兵刃伤害（受双方武力/统率影响）与谋略伤害（受双方智力影响）。 - 事件来源：普通攻击、主动战法、突击战法、持续伤害（DOT）、反击等。

深度设计剖析：为什么要有【叛逃】机制？ 在 SLG 数值生态中，高红坦克阵容（如藤甲兵盾、满宠司马盾）通常借助极致的统率堆叠与减伤战法，将常规兵刃与谋略伤害压制到极低水平。 官方将【叛逃】严格定义为：“持续性状态，每回合对武将部队造成伤害，无视防御”。 - 它在实战战法中（如武将朱儁自带战法【镇压黄巾】第2回合全体叛逃、武将程昱自带战法【十面埋伏】施加叛逃与禁疗、战法【威谋靡亢】对虚弱目标追加叛逃），虽仍继承施法者的武力（兵刃叛逃）或智力（谋略叛逃）加成，但在目标防御端完全无视受击者的统率/智力防御减免属性，直接穿透防御护甲造成真实杀伤！ - 但在机制上，【叛逃】仍保留受调控接口：它并非“无视一切的绝对神圣伤害”，依然会受到“百分比受伤害减免”（如【抚辑军民】）以及【虚弱】状态的压制，且作为持续性状态可以被【草船借箭】、【刮骨疗毒】等净化手段清除。

1.4 伤兵机制：治疗量需要通过容量与时点才能兑现

缺兵量、伤兵池与底层数值守恒约束

设单武将兵力上限为 $N$，当前实时兵力为 $T$，总缺兵量 $M = N - T$，当前可恢复伤兵容量为 $W$。 必须明确：总缺兵量绝不等于可恢复的治疗容量。任何治疗战法在结算时，实际恢复兵力同时受三道物理闸门的严格约束：

实际恢复 = min(H, W, M)
恢复结算后：T' = T + 实际恢复， W' = W - 实际恢复
若目标受到禁疗、无法获得恢复或已判定阵亡，实际恢复恒等于 0
  • $H$：战法根据武将智力/兵力计算出的名义治疗量预算；
  • $W$：受击过程中累积并经过时间衰减后的剩余伤兵池；
  • $M$：距离最大兵力上限的实际缺口（防止治疗溢出）。

伤兵池的动态注入与时间衰减法则

在实战数据复核中，伤兵池的生成与衰减遵循严密的离散规则：

单笔受击入池：ΔW = floor(0.90 × 实际损兵)
治疗消耗扣除：W' = W − 实际恢复
跨单回合衰减：W' = floor(0.90 × W)

底层数值设计哲学剖析（Why it matters）

这套严密的伤兵模型蕴含着 SLG 极其高明的数值调控哲学： 1. 为什么必须受到伤兵池 $W$ 约束，而非直接根据缺兵量 $M$ 恢复？ - 杜绝“永动机”防御毒瘤：如果治疗上限允许直接对齐缺兵量 $M$，则配置超量治疗的铁桶阵队伍只要拖到战斗后期，随时可以在残血状态下一口奶回满血，导致战后战损归零。伤兵池 $W$ 的存在，构筑了“只有承受新伤害才能转化可治疗量”的物理守恒底线，彻底掐灭了无损永动机的可能。 2. 为什么单次受击只有 90% 入池（固定 10% 硬损耗）？ - 确立交战的不可逆损耗下限：每一次交战哪怕拥有顶级急救（如【青囊】、【草船借箭】），每一次受击也至少有 10% 的兵力转化为不可挽回的战地硬死亡。这保证了无论双方续航多强，战局总是在向总兵力衰竭推进，战斗绝不会陷入无限僵局。 3. 为什么跨回合要执行 10% 的伤兵衰减？ - 赋予即时响应治疗极高战略溢价：未能及时救治的伤兵，跨回合后会以 10% 的速率伤重不治。这就让受击即刻反应的急救机制（如【草船借箭】）相对于回合初/回合末延迟治疗的休整或主动技能，具备了先天的保兵优势。

最小实战切片：两段伤害与急救的交错判定

在实战战报（如典型战报 战报_1082822_pid1077896.json 第3回合）中，周瑜在连续承受敌方战法【轻勇飞燕】多段打击时，急救与受击呈现精密的微观交错时序：

结算时序 兵力变化 结算后兵力 机制原理解析
第一段伤害前 — 4,368 初始兵力状态
第一段受击 −392 3,976 扣减兵力，即刻产生伤兵：$\Delta W = \lfloor 392 \times 0.9 \rfloor = 352$
急救判定触发 +142 4,118 受击判定通过，急救即刻兑现：$142 \le 352$，伤兵池扣减
第二段受击 −367 3,751 第二段伤害面对已恢复更新后的兵力（4,118），再次扣减
急救判定触发 +142 3,893 再次独立完成急救恢复，净损兵锁定为 475

两段合计名义伤害 759，实际恢复 284，最终净损兵 475。实战切片完全印证了：急救是插入在多段受击之间的即时补偿，不仅能有效维持兵力线降低后续伤害衰减，更能利用瞬时充足的伤兵池最大限度兑现治疗预算。

同一治疗预算的时点衰减算例验证

以下标准算例完整演示跨回合衰减对治疗兑现率的刚性侵蚀：

步骤 当前兵力 T 可恢复伤兵容量 W 当前不可战斗内恢复缺口 N−T−W 状态说明
初始状态 10,000 0 0 满兵，上限 N=10,000
受到 1,000 实际损兵 9,000 900 100 $1,000 \times 0.9 = 900$ 入池，100 成为硬损耗
名义治疗 400 介入 9,400 500 100 $400 \le 900$，实际恢复 400，W 消耗 400
再次受到 500 实际损兵 8,900 950 150 新增 $500 \times 0.9 = 450$ 入池，$500 + 450 = 950$
跨一个回合（无其他行为） 8,900 855 245 跨回合衰减 10%：$W = \lfloor 950 \times 0.9 \rfloor = 855$，硬缺口扩大为 245
名义治疗 1,000 迟滞介入 9,755 0 245 名义治疗 1,000 远超 W，受容量硬锁限制仅恢复 855

核心结论：如果该笔 1,000 治疗在跨回合理想时点内完成，原可恢复 950；仅因延迟跨过回合，直接因伤兵衰减永久丧失了 95 点兵力（只能恢复 855）。这不仅证明了治疗时点直接影响兑现效率，更深刻解释了实战中配速、急救与即时净化的不可替代性。

策划主案级的配将决策推论

基于规则基底的三层状态机逻辑，配将构筑必须遵循四条铁律： 1. 配速即生死线：辅助抢在核心输出行动前解控净化，核心输出抢在敌方爆发前出手压制兵力；同队配速脱节将导致控制驱散滞后，白白浪费回合机会。 2. 机制入口严格对齐：援护针对普攻，分担针对总伤，伪报针对被动指挥；面对不同体系的对手，必须精准核对其主力伤害或免伤所挂载的效果入口。 3. 伤兵容量决定治疗上限：单看战法面板的治疗率毫无意义，无法在伤兵产生的时间窗口内兑现的治疗预算全部是无效溢出；防禁疗、重急救、控节奏才是续航阵容的核心。 4. 攻击频次是战略双刃剑：多段攻击在提高伤害稳定性的同时，也为敌方的急救反应、反击判定和抵御消耗提供了成倍的交互窗口。

由此，本章确立了后续章节深入分析战法联动与阵容平衡的三个基本分析单元：一次行动机会、一个独立伤害事件、一笔可兑现恢复。后续所有队伍博弈，均建立在此底层时序与状态流转之上。
