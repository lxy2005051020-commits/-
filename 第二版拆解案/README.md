## 核心拆解框架

### 【第一部分】规则基底：战斗如何运行，规则如何改变选择
1. **1.1 战斗定位与战损闭环**：胜负维度、宏观资源（粮铁木/征兵时间）消耗映射、10分钟重伤机制与沙盘推进摩擦力。
2. **1.2 结算时序与行动许可**：
   - 准备阶段：官方 `被动 > 阵法 > 兵种 > 指挥` 单武将串行调度与全场速度定序机制。
   - 正式回合：先攻/普通/遇袭三层模型（先攻与遇袭抵消）与控制状态许可判定。
   - 普通攻击：配速与草船/刮骨净化时点、满宠援护受击反制、反击终战阻断风险。
3. **1.3 伤害与状态路由**：
   - 伤害双轴（路线 × 来源）与【叛逃】（无视防御的属性穿透特化解）设计定位。
   - 官方 40 个战斗特殊状态映射表（作用入口、互斥边界与实战战法锚点）。
4. **1.4 伤兵机制与容量约束**：
   - $\text{实际恢复} = \min(H, W, M)$ 守恒约束。
   - 单笔损兵 90% 入池（锁定 10% 硬损耗）与跨回合 10% 伤兵衰减机制。
   - 杜绝永动机、保障战损推进与即时急救（草船）溢价的设计哲学。

### 【第二部分】单体结算与战法投放：从名义倍率到可兑现收益
1. **2.1 一击伤害构成与属性差模型**：
   - 伤害分层拓扑（基础伤害、战法系数、修饰因子、环境因子、实际扣兵）；
   - 修饰符同侧加法对冲、跨侧独立乘算放大机制（战报 1109205 实证证明）；
   - 属性差绝对增量完全线性（50级每+50武力始终+72基础伤害，保障大R付费深度）；
   - 高额兵力基数 $F(10000)=529$ 稀释边际相对增幅，为白板平民提供凭借兵种克制与减伤战法防守反制的生存底线。
2. **2.2 兵力与输出非线性弹性**：
   - 完整 1~10,000 兵力函数 $F(N)$ 逆向分析：高兵力段输出非线性压缩，满兵降至半血仍保留 81%~85% 基础输出；
   - 辟谣民间“35%断崖”谣传，剖析残血输出骤降的真实机制（主将重伤减员、控制链覆盖与前期增益到期）；
   - 凹函数作为系统“动态阻尼器”防止先手无脑滚雪球，兼顾先手压血与残兵反扑的动态博弈。
3. **2.3 战法名义预算与方差心理学**：
   - 名义预算初筛标尺与五大实战物理兑现闸门；
   - 锚定三战战法生态：关羽/吕布（高方差爆发型）vs 避实击虚/落凤（平稳节奏型）vs 士别三日/用武通神（确定性基石型）；
   - 求解精确二项分布：方差改变战局达标概率（高方差提供破防爆头杠杆，低方差确保多穿稳定）；
   - 8回合有限窗口下准备机制的频次损耗（期望 2.445 次）与超额数值/控制补偿；
   - GaaS 商业长线生态下的“方差心理学”：弱者逆袭的多巴胺源泉与战败保护伞。
