## 核心拆解框架

### 【第一部分】规则基底：战斗如何运行，规则如何改变选择
1. **1.1 战斗定位与战损闭环**：胜负维度、宏观资源（粮铁木/征兵时间）消耗映射、10分钟重伤机制与沙盘推进摩擦力。
2. **1.2 结算时序与行动许可**：
   - 准备阶段：官方 `被动 > 阵法 > 兵种 > 指挥` 单武将串行调度与全场速度定序机制。
   - 正式回合：先攻/普通/遇袭三层模型（先攻与遇袭抵消）与控制状态许可判定。
   - 普通攻击：配速与草船/刮骨净化时点、满宠援护受击反制、反击终战阻断风险。
3. **1.3 伤害与状态路由**：
   - 伤害双轴（路线 × 来源）与【叛逃】（无视防御的属性穿透特化解）设计定位。
   - 官方 40 个战斗特殊状态映射表（作用入口、互斥边界与实战战法锚点）。
4. **1.4 伤兵机制与容量约束**：
   - $\text{实际恢复} = \min(H, W, M)$ 守恒约束。
   - 单笔损兵 90% 入池（锁定 10% 硬损耗）与跨回合 10% 伤兵衰减机制。
   - 杜绝永动机、保障战损推进与即时急救（草船）溢价的设计哲学。

### 【第二部分】单体结算与战法投放：从名义倍率到可兑现收益
1. **2.1 一击伤害构成与属性差模型**：
   - 伤害分层拓扑（基础伤害、战法系数、修饰因子、环境因子、实际扣兵）；
   - 修饰符同侧加法对冲、跨侧独立乘算放大机制（战报 1109205 实证证明）；
   - 属性差绝对增量完全线性（50级每+50武力始终+72基础伤害，保障大R付费深度）；
   - 高额兵力基数 $F(10000)=529$ 稀释边际相对增幅，为白板平民提供凭借兵种克制与减伤战法防守反制的生存底线。
2. **2.2 兵力与输出非线性弹性**：
   - 完整 1~10,000 兵力函数 $F(N)$ 逆向分析：高兵力段输出非线性压缩，满兵降至半血仍保留 81%~85% 基础输出；
   - 辟谣民间“35%断崖”谣传，剖析残血输出骤降的真实机制（主将重伤减员、控制链覆盖与前期增益到期）；
   - 凹函数作为系统“动态阻尼器”防止先手无脑滚雪球，兼顾先手压血与残兵反扑的动态博弈。
3. **2.3 战法名义预算与方差心理学**：
   - 名义预算初筛标尺与五大实战物理兑现闸门；
   - 锚定三战战法生态：关羽/吕布（高方差爆发型）vs 避实击虚/落凤（平稳节奏型）vs 士别三日/用武通神（确定性基石型）；
   - 求解精确二项分布：方差改变战局达标概率（高方差提供破防爆头杠杆，低方差确保多穿稳定）；
   - 8回合有限窗口下准备机制的频次损耗（期望 2.445 次）与超额数值/控制补偿；
   - GaaS 商业长线生态下的“方差心理学”：弱者逆袭的多巴胺源泉与战败保护伞。

### 【第三部分】战前配将与动态联动：承伤转化、频次代价与时序博弈
1. **3.0 战损本质与沙盘闭环**：净损兵（1.56%~2.98%）与累计承伤分层解构，大地图补兵时间、粮草消耗与低损驻守连穿机制。
2. **3.1 锁定配置与设计构型**：反击盾（墩墩盾）与慷慨弓（甘太程）铁三角构型，入场面板与快照分离。
3. **3.2 动态联动与输出反转**：夏侯惇单核受击反制超 2 万伤害，承伤位反转为第一输出入口，满宠回填与曹操净化的双核分工。
4. **3.3 事件链实证与频次代价**：太史慈第二击（E176-263）导致 2,188 逆差，当锋伪报与草船净化的时钟控制权争夺。
5. **3.4 消融对照与策划调优抓手**：首回合双普攻分支对照，局部组件消融边界，面向数值策划的 3 大平衡调控旋钮（时钟判定优先级、伤害率与副将门槛、死兵转化率）。
6. **3.5 配速工程学本质**：非盲目抢一速，而是围绕“保护关键事件生命周期窗口”进行的属性置换。
7. **3.6 玩家决策矩阵**：6 大配将取舍与系统设计意图闭环。

### 【第四部分】受控机制验证与生态克制矩阵：从战损反应机制、真实战报大盘到SLG攻防流派食物链
1. **4.0 验证方法论与数据工程底座**：大盘数据清洗规约、同构配置过滤（4.3万大盘 → 21份精确同配置PVP）与逐事件时序账本连续性校验。
2. **4.1 机制受控验证：攻击频率的边际代价与反应充能**：固定前置伤害预算 1600 对比单段与多段普攻，三层机制过滤漏斗（类型匹配、拦截时序、回填效率）。
3. **4.2 真实大盘印证：流派对抗矩阵与实战战损分化**：甘太程绝对压制（1.56%~13.93%净损率）vs 皇马枪机制反转（41.31%~82.40%净损率）。
4. **4.3 破局点深度诊断：复合高阶控制对频率惩罚的降维打击**：皇马枪首回合事件流解构，看破穿透常驻减伤与当锋伪报阻断时钟栈。
5. **4.4 体系天敌与设计安全阀：真实伤害与输出入口错配**：火攻真实伤害惩罚（藤甲易伤乘算放大）与功不唐捐（不可驱散）对反击闭环的降维打击。

### 【第五部分】三类环境配置尝试：同一套墩墩盾，应该为哪种风险付出一个战法位
1. **5.1 固定阵容与单变量对照**：A（原配藤甲+非攻）、B（御敌屏障替代藤甲）、C（刮骨疗毒替代非攻）；战法生态位与机会成本（A级下放成本 vs T0战略挤占成本）。
2. **5.2 火/法多：B用后程兵刃保护交换前段覆盖**：M1受控防护预算模型推演与交叉点曲线；“兵力即输出”动态负反馈衰减折现。
3. **5.3 中断多：C增加一次净化机会，交换非攻持续治疗**：自洽回填飞轮闭环 vs 偶发性外生救急；刮骨判定机制与不可清除状态边界。
4. **5.4 配速实验：先行动的净化，未必处理得到新控制**：满宠先攻净化的“时差盲区”；M2模型64组二元状态门禁推演与实战先验敏感度区间。
5. **5.5 交叉验收矩阵与指标体系**：3配置×3压力九格对照标准；新增终局回合（TTK）与双方兵力断崖拐点等核心战斗指标。
6. **5.6 玩家取舍与策划设计法则**：用一个战法位购买特定保障并承担共存成本；坚持商业系统预埋安全阀原则，反对无脑全局免控增强。
