## 2. 口径说明与指标边界

| 分析维度 | 采用口径 | 论证边界与限制 |
|---|---|---|
| **净损兵** | 净损兵 = 累计损失兵力 − 实际恢复兵力 | 累计承伤含反复受损兵力；净损兵不直接等同于大地图死兵数或实际补兵耗铜量。 |
| **低战损成因** | 减伤基底 + 援护聚伤 + 被动反击 + 休整充放电闭环 | 两场对局为低战损典型样本，不用于外推全赛季环境绝对胜率。 |
| **局部双普攻切片** | 闭合于太史慈第 1 回合行动末尾派生链 | 仅量化当次分支的即时兵力交换收益，不传播未来随机数、不构造全场反事实。 |
| **气凌消融实验** | 仅冻结已发生战报中 E195 气凌直接命中伤害 | 证明已记录切片中的直接贡献；不声称卸下战法后整场战局演化固定不变。 |
| **当锋与草船博弈** | 战报 5 中 G2/E217~240（反击先于当锋结算）与 G3/E198~205（草船解伪报） | 严格以日志时钟为准，伪报无法回溯已发生反击伤害，草船净化提供重启窗口。 |
| **配速敏感性** | 依据 R1 统计快照的静态速差分析门槛 | 门槛差值代表同优先级静态敏感度，非自由属性点推荐加点方案。 |

## 3. 复现验证指南

本案全部数据均可通过以下步骤离线完整复现：
1. `audit_details.py`：重算显式战法伤害、有效治疗归属与首回合双普攻分支对照；
2. `build.py`：由 Markdown 自动构建 HTML、8 页规范 PDF 及架构图表；
3. `verify.py`：重演 478 条底层兵力变化、校验 PDF 页面边框与字符预算；
4. `package.py`：完整性哈希校验与自动化归档打包。
