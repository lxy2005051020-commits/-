## 🧭 核心策划拆解框架

1. **3.0 先确认：低的是净损兵，不是从未受伤**
   - 净损兵与累计承伤的分层解构（蓄水池动态充放电）；
   - SLG 宏观沙盘战损经济学：净损兵 1.56%~2.98% 对前线营帐补兵、粮草消耗与低损驻守连穿的战略意义。
2. **3.1 锁定配置：相同队名，分别记录**
   - 盾队（曹操+夏侯惇+满宠，俗称“墩墩盾”）与弓队（甘宁+太史慈+程普，经典“甘太程”演化变种）配置拓扑；
   - 战报快照属性与入场初值分离。
3. **3.2 画出联动：让承伤位置成为输出入口**
   - 承伤位置反转为第一输出入口机制：夏侯惇单核受击反制超 2 万伤害；
   - 续航分工解耦：满宠负责常态血线回填，曹操负责异常状态净化；
   - 藤甲兵动态减伤（-56.46% 至 -68.46%）的条件依赖性。
4. **3.3 截取事件链：第二次攻击，究竟帮助了谁**
   - 首回合太史慈第二击（E176–263）全事件链逐帧复盘；
   - 行动频次代价的量化实证：第二击使弓队产生 2,188 的兵力交换逆差；
   - 当锋伪报与草船净化的时钟控制权之争（当锋无法逆转时间戳，净化与休整迅速回填）。
5. **3.4 设置对照与消融分析**
   - 首回合双普攻分支净损优势量化；
   - 局部组件消融边界与反事实约束；
   - **策划调优抓手（Design Tuning Levers）**：时钟判定优先级、伤害率系数与死兵转化率调控。
6. **3.5 配速：先保入口，再判断净化窗口**
   - 配速工程学本质：非盲目卷一速，而是争夺状态生命周期窗口；
   - 满宠先攻机制与曹操卡位夏侯惇行动前的解控敏感性。
7. **3.6 落到玩家选择：优势有条件，调整有损失**
   - 6 大配队决策矩阵与系统设计意图闭环。
