## 🎯 策划拆解案核心方法论提炼总结

### 一、优秀拆解案的“黄金五层递进结构”
1. **What（表现层）**：精准提炼界面信息架构（IA）、按键交互、视觉反馈，杜绝纯截屏流水账；
2. **How（机理层）**：还原状态转移矩阵、数据结构、判定帧、物理输入缓冲或伤害公式；
3. **Why（意图层）**：剖析策划为什么这么做？心流体验控制、经济防通胀、商业化卡点还是留存漏斗？
4. **Data（量化层）**：以等值体力、小时、RMB成本或数学期望建立度量衡，用数字说话；
5. **If（改良层）**：敏锐指出系统缺陷与体验痛点，给出具备工程可落地性的手术刀式再设计方案。

### 二、三大通用避坑警示
- ❌ **警惕“UI说明书式流水账”**：罗列按钮和界面不叫拆解，只有剖析“为什么”和“底层闭环”才是策划的深度；
- ❌ **警惕“缺乏量化的大词空话”**：避免空谈“节奏好、打击感强”，务必落地为判定帧、硬直时间、减伤公式、期望抽数与成长周期；
- ❌ **警惕“报喜不报忧的纯赞美”**：成熟的商业游戏必然有权衡和缺陷（如绝区零的修脚疲劳、深空之眼的资源过快贬值），客观的 Critique 才是区分初级策划与主策划的核心标尺。
